# walmart-hurricane-project
--------------------------
## How to Access and Run the Project

### 1. Get the Repository

Clone the project repository from GitHub:

```bash
git clone https://github.com/prabhnoor14/walmart-hurricane-project
```

Alternatively, download the repository by selecting **Code → Download ZIP** on GitHub and extracting the files. If you are running the project in Colab, the first code cell handles this step for you.

### 2. Open the Notebook in Google Colab

1. Go to [Google Colab](https://colab.research.google.com/).
2. Select **File → Open notebook → GitHub**.
3. Paste the team repository URL: `https://github.com/prabhnoor14/walmart-hurricane-project`.
4. Select `notebooks/team_notebook.ipynb`.

You can also [open the team notebook directly in Google Colab](https://colab.research.google.com/github/prabhnoor14/walmart-hurricane-project/blob/main/notebooks/team_notebook.ipynb).

### 3. Access the Project Data

The first code cell automatically clones the repository into the Colab environment when you run it. The repository includes the `data/` directory and all supplied datasets.

### 4. Run the Notebook

1. In Colab, select **Runtime → Run all** to execute the notebook from beginning to end.
2. The notebook will load and clean the datasets, query the SQLite database, retrieve weather data through the Open-Meteo API, and perform the five analyses.

An internet connection is needed to clone the repository and retrieve weather data.
